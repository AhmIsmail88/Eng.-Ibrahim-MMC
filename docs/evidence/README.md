**ما يوضع هنا:**

- `phase0_pdf_ar_spike.png|pdf` — نتيجة بوابة إثبات PDF العربي: جدول متعدد الصفحات، ترويسة متكررة، نص عربي/إنجليزي مختلط، أكواد وأرقام لاتينية.
- `phase0_rtl_dark.png`, `phase0_rtl_light.png` — لقطات الواجهة بالوضعين.
- `phase7_clean_machine.md` — تقرير اختبار جهاز Windows نظيف (بدون Python).
- `phase7_screens/` — لقطات الشاشات المكتملة عند التسليم.

**قاعدة:** كل ملف هنا يُذكر في تقرير المرحلة المقابلة بمقاسه وتاريخه ونسخة الإصدار. لا صور توضيحية من مصادر خارجية بلا ذكر ترخيصها.
