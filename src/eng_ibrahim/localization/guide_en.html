User guide

This maintenance management system runs on this computer without internet. All data is stored in your user folder on this machine, not in the program folder, so updating or reinstalling the program never deletes your data.

1. Getting started: first run and users

On first run a wizard asks for the station name, base currency, the administrator account and the backup folder. Keep the recovery code shown at the end in a safe place.

The Users screen (administrators only) adds accounts with four roles:

  • Administrator: everything, including users and closing/reopening work orders.
  • Editor: enters and edits data and runs work orders.
  • View & print: sees data and produces reports.
  • View only: sees data without changing anything.

With a single user and no password, the program opens directly without a login screen.

2. Master data

The Master data screen has one tab per reference list: locations, categories, types, failure codes, task library, units, warehouses, currencies and operating calendars.

  • Start with locations: every asset must be in one.
  • Operating calendar: set working days and shift hours with “Working hours”. An end time earlier than the start is a night shift ending the next day.

3. Assets, equipment and meters

  • New asset: code, name, category and location are required; codes are unique.
  • The asset profile has tabs: overview, technical data, meters, parts used, attachments and full history.
  • Meters (running hours, km, cycles): a new reading cannot be lower than the previous one, nor higher than a later one. Corrections are recorded as a documented correction; the original reading stays in the history.
  • Import assets: a CSV or Excel file with columns asset_code, asset_name_ar, category_code, location_code. The whole file is checked first; nothing is imported if a single row is wrong.
  • QR labels prints labels for the assets listed.
  • Archive instead of delete: an archived asset leaves the lists but keeps its history.

4. Vehicles workshop

  • New vehicle: fleet code, name and location are required; the current odometer can be entered straight away.
  • Record odometer from the Odometer tab. Same rule as all meters: a lower value is refused.
  • Service programme: “Add service”, e.g. every 10,000 km or every 6 months, due on whichever comes first. Leave one empty to use only the other.
  • The Alerts column shows due or overdue services and insurance/licence expiring within 30 days or expired.
  • “Needs attention only” lists vehicles with an alert.

5. Failure reports

In Corrective Maint. record a New report with the fault and priority. After investigation use Convert to work order; the report is linked and cannot be converted twice.

6. Work orders

Life cycle:

Draft → Open (submit) → Assigned (assign a technician) → In progress (start) → Completed (complete) → Closed (close, administrators).

  • Orders can be put on hold and resumed, or cancelled before work starts, with a reason.
  • Complete requires all mandatory tasks done and whether the equipment returned to service.
  • Reopen after completion or closing is for administrators, with a reason.
  • Cost = labour hours × technician rate + parts issued + external expenses. Amounts in another currency are not added to the total, and the cost status says so.
  • Closed and cancelled orders are read-only: no tasks, time, expenses or parts.

7. Preventive maintenance

  • New plan: by date (every N days/weeks/months/years), by meter (every N hours/km), or both (whichever first).
  • Plan states: not due, due soon, due, overdue, awaiting completion of its work order.
  • Generate work order by hand, or automatically once a day (Settings). Automatic orders are created as Draft so you can review them.
  • If several dates were missed while the program was closed, the older ones are logged as skipped and the latest stays due — never a pile of orders at once.
  • Completing a PM work order schedules the next date automatically.
  • PM calendar shows the dates by day.

8. Checklists

Prepare templates in Checklists; inside a work order use Start inspection and record each item. Failed items are counted in their own column.

9. Spare parts and stock

  • Receive increases stock and updates the weighted average cost.
  • Issue to work order reduces stock and adds the cost to the order. Quantity reserved for an order is available to that same order.
  • A return from a work order cannot exceed what was issued to it.
  • Adjust and Quick stock count correct balances with a reason; a negative adjustment never eats reserved stock.
  • “Low stock only” lists parts below their reorder point.
  • Import parts: CSV or Excel with part_code, name_ar, unit_code (optional reorder_point).

10. Suppliers and purchase requests

Create the request, approve it, and receive it when goods arrive: all lines enter stock together. If one line fails nothing is posted, and a request cannot be received twice.

11. Dashboard and search

  • Click any card to open its list pre-filtered, e.g. “Overdue PM” opens only overdue plans.
  • Card colours: red overdue, orange warning, green fine.
  • Global search (Ctrl+K or the search box at the top): assets, vehicles, work orders and parts by code, name or plate; Enter opens the result.

12. Reports

In Reports choose a report and period, then Preview or export PDF / Excel. Available: equipment register, PM schedule, work orders register, single work order, stock balance and maintenance cost.

13. Backup and restore

  • The program makes an automatic backup once a day and keeps the latest 10 in the backup folder (can be switched off in Settings).
  • Backup now at any time. Copy the backup folder to a USB drive or another computer regularly.
  • If the last backup is older than 7 days, the status bar shows an orange warning.
  • Restore from file verifies the archive and takes a safety backup of your current data before replacing it. Restart the program afterwards.
